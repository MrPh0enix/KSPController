Spacecraft controller for Kerbal Space Program

## Installation
1. Install Kerbal Space Program
2. Copy krpc v0.6.0 from https://github.com/krpc/krpc/releases?utm_source=chatgpt.com#release-v0.6.0
3. Copy the contents of GameData into the GameData folder of your installation.
4. pip install krpc
5. Open the game and start the server
